## How to use packing program

1. Run main.py

## Commands:

### list
shows current containers and items

### adit \<name>
adds an item with the name provided (one word) to the current container

### adcon \<name>
adds a container with the name provided (one word) within the current container

### remove \<name>
removes item or removes container (if empty) within the current container

### enter \<name>
enters the container with name `<name>` if it exists

### back
exits current container (unless at root)

### tree
displays recursively all the items and containers with proper indentation

### exit
exits the program
